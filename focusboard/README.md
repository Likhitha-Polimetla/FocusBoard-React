# FocusBoard

A responsive task management dashboard built using React and Vite.

## Features

- Responsive desktop and mobile layout
- Create, edit, and delete tasks
- Delete confirmation
- Task status management
- Search tasks by title (case-insensitive)
- Filter tasks by status and priority
- Dynamic task statistics
- Completion percentage
- Three-slide Focus Notes carousel
- LocalStorage persistence
- Accessible form labels and button labels

## Tech stack

- React
- JavaScript
- CSS
- Vite
- Lucide React icons
- Browser LocalStorage

## Run locally

1. Install Node.js.
2. Open this project folder in VS Code.
3. Open the terminal in the project folder.
4. Run:

   npm install

5. Start the development server:

   npm run dev

6. Open the local URL shown in your terminal.

## Production build

Run:

npm run build

The production files will be generated in the `dist` folder.
